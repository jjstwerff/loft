# 2D drawing — the shipped tool and how to run the loop on it

The 2D instance of the method is `sketch/draw.py` (repo root). It is a persistent
renderer over an annotated text scene file; you edit the scene, it re-renders, and
it writes both a cheap text channel and an image you `Read`.

## Run it

```bash
python3 sketch/draw.py path/to/scene.draw     # renders + watches; re-renders on save
SKETCH_OUT=/dir python3 sketch/draw.py scene.draw   # choose output dir
```

Requires Pillow. Outputs go to `$SKETCH_OUT` (default `<tmp>/loft_sketch/`), **never
into the repo**:

- `stats.txt` — **the cheap channel**: ASCII density map + element bboxes + `CHECK`
  results + a **composition / notan report**. Read this most iterations; it's text.
- `canvas.png` — the drawing (the expensive look; spend on gestalt + affect).
- `canvas_check.png` — drawing + target guides (green landmark, gray bboxes, red =
  failed check). Read when you need to *see* a gap.
- `preview.png` — a smaller, cheaper image look.

Editing the scene file *is* undo (reload on save). Rendering is supersampled, so
edges are anti-aliased — never hand-place anti-aliasing.

## Scene grammar

Coords are **fractions** of the paper (0..1); origin top-left, **y grows down**.
Gray `L` is 0..1 (0 = black). Colour `rgb` is 0..255.

```
size WxH
Background top=A bottom=B                 grayscale sky gradient (A top → B bottom)
Background topc=R,G,B botc=R,G,B           colour sky gradient
name <element>                            tag the following marks (so they're measurable)
Line (x1,y1) - (x2,y2) [w=N]
Circle (cx,cy) r=R [n=N] [flat=F] [w=N] [fill=L | rgb=R,G,B]   round (aspect-corrected)
Poly (x1,y1) (x2,y2) ... [w=N] [fill=L | rgb=R,G,B]            stroke, or filled
landmark <name> = <value>
check <prop> <op> <term> [tol T]          op: ~ < > <= == ; arithmetic on the RHS only
                                          prop: <element>.{left,right,top,bottom,cx,cy,w,h}
# ...                                      comment / SHOULD note (ignored, searchable)
```

- A shape with `fill=`/`rgb=` is **filled**; with neither it's **stroked**. Painters'
  order = source order (draw the sky, then masses, then detail on top).
- `flat=F` squashes a circle vertically (negative F makes it taller — useful for an
  egg/face oval).
- Put the **target feeling** and the **`# SHOULD:`** intent next to each element as a
  comment; `grep -n SUN scene.draw` to find a spot again.

### The composition / notan report (in `stats.txt`)

Global facts no per-element check can give: L/R and top/bottom weight balance, the
**center-of-mass of the darks vs the thirds grid**, the **value spread** (notan
health — muddy mid vs clear dark/light), and the **largest flat region** (dead
space or dominant field). Use it as your digital thumbnail: judge composition on
this coarse map, not by scrutinising the detailed image.

## Earned 2D rules (read before drawing; they save whole passes)

- **Round circles** are aspect-corrected by `Circle` already — equal fractional radii
  would otherwise render as an ellipse on non-square paper.
- **A bare circle reads as a ball.** A *sun* needs short radial rays (its diagnostic
  cue) — but **not** long beams across the scene (those read as wires).
- **A cloud** = one soft, irregular, ragged silhouette with the interior withheld —
  **not** crisp overlapping circles (those read as bubbles). For a *dark* cloud, fill
  it dark with a soft/low edge; a crisp outline can't be ominous.
- **Dominance ≠ looming.** A big mass that floats high with empty space under it
  doesn't oppress; oppression needs the underside *close* over the subject and the
  dead band removed. (Don't trust `cloud.bottom < house.top` — that only says
  "above"; check a *small* gap: `cloud.bottom > house.top - 0.06`.)
- **Each measurable thing gets its own `name`.** Tagging a sub-part (chimney, light
  spill, smoke) under a parent bloats the parent's bbox and breaks its checks.
- **The composition critic tracks DARK mass** — in a light-on-dark dusk scene the
  focal point is the *bright* face/window, which it can't see, so it may cry
  "dead-centre/static" while the real focal is well-placed. Judge the bright focal
  by eye.
- **Faces** (the hardest 2D subject):
  - Go **line-forward** — wrinkles *are* lines, and line is recognition's native
    channel. Proportions via checks (eyes at the head's vertical midline, nose below
    eyes, mouth below nose, ~5 eyes wide).
  - **Pupils give gaze and life** — a lidded almond with no pupil is a blank mask.
  - **Flat fills make a mask.** A living face needs **warm-toned skin** (a grey face
    reads as a corpse) and **soft edges**; even then it's a *stylized illustration*,
    not realism — flat fills can't model the form. Name that floor; don't chase it.
  - **Commit to one scale** — a portrait (head-and-shoulders, cropped) *or* a figure
    (small head, ~1:7 body). A portrait head on a figure body is a bobblehead.
  - **Age cue-set:** grey hair (often a bun), hooded eyes + bags, nasolabial folds,
    a thin downturned mouth, forehead/eye-corner lines. A few bold, not many faint.

## A worked example

`sketch/scene.draw` + `sketch/example.png` are the canonical worked example — an old
woman at dusk before her lit house. It exercises colour, value, the composition
report, named elements, and the metric checks. Read the scene file alongside the
render to see how the grammar maps to the image.

## The arc a real drawing went through (so you expect the shape)

symbol block-in (cube + bubbles) → coherent *place* (real house, world that holds)
→ *composed* place (low horizon, looming mass — mood by arrangement) → *value* (dark
cloud, glowing horizon, lit window — the dusk feeling) → *colour + soft edges* (warm
skin, warm/cool dusk — the largest single jump). Each step was one pass with a
find→fix→verify; none arrived in one shot.
