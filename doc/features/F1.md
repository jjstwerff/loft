# @F1 — Nullable value semantics — in-band sentinels + null-fallback arithmetic

## What it is

A value can be present or absent. An absent value is `null`. Doing arithmetic with a `null` simply produces `null` again instead of stopping your program.

## How it aids you

Missing data — a lookup that found nothing, a field never filled in — no longer has to be a special case that crashes. The absence flows through your calculation as `null`, so you can carry on and decide what to do about it at the end rather than guarding every step.

## Example

```loft
fn main() {
    a = null as integer;   // a holds no value
    b = a + 10;            // arithmetic on null gives null, no crash
    println("{a} {b}");    // null null
    println("still running");
}
```
