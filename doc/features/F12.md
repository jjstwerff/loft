# @F12 — Struct records — fields, `= default`, `computed`, `limit`/`not null`/`assert`

## What it is

A named type that groups related values together as fields. Create one by naming its fields; read a field with a dot.

## How it aids you

Instead of juggling several loose variables that belong together, you keep them in one named thing — easier to pass around, and the field names say what each value means.

## Example

```loft
struct Point { x: integer, y: integer }
fn main() {
    p = Point { x: 3, y: 4 };
    println("({p.x}, {p.y})");    // (3, 4)
}
```
