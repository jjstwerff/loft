# @F12 — Struct records — fields, `= default`, `computed`, `limit`/`not null`/`assert`

## What it is

A named type that groups related values together as fields. Create one by naming its fields; read a field with a dot. Fields can carry modifiers: `const` (set once at construction), `= default` (a value to use when the caller omits it), `limit(lo, hi)` (a range the field must stay inside), `not null`, and `assert(...)` for anything else.

## How it aids you

Instead of juggling several loose variables that belong together, you keep them in one named thing — easier to pass around, and the field names say what each value means. The modifiers put the rules next to the data they constrain, so an identifier that must never change, or a value that must stay in range, says so where it is declared rather than in every function that touches it.

## Example

```loft
struct Account {
    const id: integer,
    name: text = "unnamed",
    balance: integer limit(0, 1000000),
}

fn main() {
    a = Account { id: 7, balance: 250 };
    println("{a.id} {a.name} {a.balance}");   // 7 unnamed 250
    a.balance = 300;                          // an ordinary field changes
    println("balance {a.balance}");           // balance 300
}
```

`name` was omitted at construction, so it took its default. Assigning `a.id` is a compile error — a `const` field is fixed once the record exists.
