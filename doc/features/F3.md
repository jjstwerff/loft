# @F3 — Primitive scalar types (integer, float, single, boolean, character)

## What it is

The everyday value types every loft program uses: whole numbers (`integer`), decimals (`float`), yes/no (`boolean`), and single characters (`character`).

## How it aids you

These are the building blocks you reach for constantly. Each variable says which one it holds, so the meaning of your data is clear and a slip like putting text where a number belongs is caught for you.

## Example

```loft
fn main() {
    count: integer = 42;
    ratio: float = 3.5;
    ok: boolean = true;
    letter: character = 'A';
    println("{count} {ratio} {ok} {letter}");   // 42 3.5 true A
}
```
