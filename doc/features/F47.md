# @F47 — Library imports / module system (`use` forms, `pub`)

## What it is

`use` brings names — functions and types — from another `.loft` file or an installed library into your file, so you can call them directly. Put `use` lines at the top of the file.

## How it aids you

Split a program across files and pull in shared code — your own helpers or a published library — without copying it, so each file stays focused and the same code is written once and reused.

## Example

Two files side by side. `greetlib.loft` offers a public function; `main.loft` imports it:

```loft
// greetlib.loft
pub fn greet(name: text) -> text {
    "hello, {name}"
}
```

```loft
// main.loft  — imports greet from greetlib
use greetlib::greet;

fn main() {
    println(greet("loft"));   // hello, loft
}
```

The common forms of `use`:

```loft
use mathlib;                 // bring in every public name
use mathlib::sqrt;           // bring in just one name
use mathlib::(sqrt, pow);    // bring in several (parentheses required)
use mathlib::sqrt as root;   // rename on import
use mathlib as m;            // reach names as m::sqrt
```
