# @F5 — Type conversions — implicit, format-only, and explicit `as`

## What it is

The `as` cast converts a value from one type to another on purpose: `pi as integer`, `"42" as integer`, `'A' as integer`. You ask for the conversion, so it happens exactly where you write it.

## How it aids you

You get to move between types deliberately — round a decimal down to a whole number, read a number out of text, get a character's code — with the conversion visible in the code. Nothing silently changes type behind your back.

## Example

```loft
fn main() {
    pi: float = 3.75;
    whole = pi as integer;     // 3  (drops the fraction)
    parsed = "42" as integer;  // text turned into a number
    code = 'A' as integer;     // 65 (the character's code)
    println("{whole} {parsed} {code}");   // 3 42 65
}
```
