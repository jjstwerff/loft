# @I82 — Sandbox policy & enforcement

## What it does

Defines what a running loft program is allowed to touch — filesystem, network, environment, subprocesses — as named capability groups, and enforces those limits at the boundary where the program meets the host. It is how a program can be run with least privilege instead of unrestricted access to the machine.

## Where it lives

`src/sandbox.rs`
