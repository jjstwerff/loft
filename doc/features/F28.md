# @F28 — `for`-in loops — ranges, loop attributes, filtered, `rev()`

## What it is

Repeat a block once for each item in a collection, or for each number in a range.

## How it aids you

Walk a list or count through a range without managing an index by hand — you name the current item and the loop hands you each one in turn.

## Example

```loft
fn main() {
    total = 0;
    for i in 1..=5 { total = total + i; }
    println("sum 1..=5 = {total}");    // sum 1..=5 = 15
}
```
