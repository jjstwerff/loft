# @I70 — Database — alloc / persistence / journal / snapshot / schema

## What it does

Manages all of a program's stores together with their schema, and provides allocation, persistence, journaling, and snapshotting on top of the raw heap. It is what makes loft's heap durable and recoverable rather than purely in-memory.

## Where it lives

`src/database/` (entry point `src/database/mod.rs`)
