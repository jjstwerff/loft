# @F37 — Operator set — arithmetic/comparison/logical/bitwise/unary, `**`

## What it is

The usual operators, all built in: arithmetic (`+ - * / %` and `**` for powers), comparison (`== \!= < <= > >=`), logic (`and`, `or`, `\!`), and bit operations (`| & ^ << >>`).

## How it aids you

Everything you expect for calculating and comparing is there with familiar spelling and sensible precedence, so expressions read the way you would say them aloud — and one line can do real work.

## Example

```loft
fn main() {
    a: integer = 7;
    b: integer = 2;
    println("{a + b} {a - b} {a * b} {a / b} {a % b} {a ** b}");   // 9 5 14 3 1 49
    println("{a > b} {a == b} {a > 0 and b > 0} {a | b} {a & b}"); // true false true 7 2
}
```
