# @F39 — Math & trigonometry library

## What it is

A set of ready-made number functions: absolute value, the smaller or larger of two values (`min` / `max`), square root, powers (`pow`), the trigonometry functions (`sin` / `cos` / `tan`), rounding (`floor` / `ceil` / `round`), logarithms, and the constant `PI`.

## How it aids you

Reach for the operation you need by name instead of spelling out the formula by hand — one call for a square root, a power, or an angle — so numeric code stays short and reads the way you would say it out loud.

## Example

```loft
fn main() {
    println("abs: {abs(-7)}");            // abs: 7
    println("min/max: {min(3, 9)} {max(3, 9)}");  // min/max: 3 9
    println("sqrt: {sqrt(144.0)}");       // sqrt: 12
    println("pow: {pow(2.0, 10.0)}");     // pow: 1024
    println("cos(0): {cos(0.0)}");        // cos(0): 1
    println("pi: {PI}");                  // pi: 3.141592653589793
}
```
