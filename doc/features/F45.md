# @F45 — `sizeof()`

## What it is

`sizeof(...)` tells you how many bytes a type or value takes up when it is packed for storage — for a built-in type, one of your own structs, or a variable.

## How it aids you

Know the storage footprint of your data before you write it out — useful when you save records to a file or reason about how much space a large collection will need.

## Example

```loft
struct Point { x: integer, y: integer }

fn main() {
    println("integer: {sizeof(integer)}");  // integer: 8
    println("u8: {sizeof(u8)}");            // u8: 1
    println("u16: {sizeof(u16)}");          // u16: 2
    println("Point: {sizeof(Point)}");      // Point: 16
}
```
