# @I61 — Stack slot allocator

## What it does

Assigns each local variable and temporary a fixed slot on the runtime stack, deciding the layout of every function's stack frame. Stable slot numbers let both the interpreter and the native backend read and write locals by position.

## Where it lives

`src/variables/` (entry point `src/variables/mod.rs`)
