# @F18 — `const` parameters

## What it is

Put `const` in front of a parameter's type to promise the function will never change that value. It is a guarantee written right in the signature, and Loft holds you to it — trying to change it is an error.

## How it aids you

Anyone reading the function knows at a glance that this input is safe: it goes in and comes back untouched. You can hand over your data without worrying it will be altered behind your back, and if the code ever tries to change it, you find out straight away instead of chasing a surprise later.

## Example

```loft
struct Account {
    balance: integer
}
fn describe(acct: const Account) -> text {
    "balance is {acct.balance}"
}
fn main() {
    a = Account { balance: 500 };
    println(describe(a));           // balance is 500
    println("still {a.balance}");   // still 500
}
```
