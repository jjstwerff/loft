# @F26 — Interfaces & bounded generics (`<T: A + B>`, operator interfaces)

## What it is

A bound like `<T: Ordered>` lets a generic function require that its type can do certain things — here, be compared with `<` and `>`. An interface names a group of abilities (Ordered for comparing, Addable for adding, and so on) that a type either has or does not.

## How it aids you

Write one function that works for every type that can be compared — numbers, text, and more — while Loft guarantees you only use abilities each type genuinely has. You get broad reuse without giving up the checks that catch mistakes early.

## Example

```loft
fn largest<T: Ordered>(a: T, b: T) -> T {
    if a > b { a } else { b }
}
fn main() {
    println("{largest(3, 7)}");        // 7
    println("{largest(2.5, 1.5)}");    // 2.5
    best = largest("apple", "pear");
    println(best);                     // pear
}
```
