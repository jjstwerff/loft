# @F38 — Arithmetic safety — overflow/÷0 → null, nullable peers

## What it is

When a calculation cannot give a real answer — a number grows too big to hold, or you divide by zero — loft produces `null` for that result and keeps running, instead of crashing.

## How it aids you

One bad calculation no longer takes down the whole program. The trouble spot becomes a `null` you can spot and handle (often with `??` to supply a fallback), the way a spreadsheet shows an error in one cell while the rest of the sheet still works.

## Example

```loft
fn main() {
    big: integer = 9_000_000_000_000_000_000;
    total = big + big;          // overflow -> null, no crash
    println("{total}");         // null
    divisor: integer = 0;
    safe = 100 / divisor ?? -1; // divide by zero -> null -> fallback
    println("{safe}");          // -1
    println("done");            // program keeps running
}
```
