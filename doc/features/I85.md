# @I85 — Engine-host kernel natives

## What it does

The set of low-level host primitives the engine exposes to running loft code — the kernel-level mechanisms, beyond ordinary stdlib functions, that let a program reach into the engine itself. It is the controlled boundary between loft-level code and the host runtime's internals.

## Where it lives

`src/engine_host.rs`
