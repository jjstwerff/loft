# @F54 — Browser / WASM target (`--html` / `--native-wasm`)

## What it is

The browser target. `loft --html prog.loft` compiles your program to WebAssembly and bundles it into a single self-contained HTML file you can open in any browser. `loft --native-wasm prog.loft` emits just the `.wasm` module when you want to embed it yourself.

## How it aids you

The same loft program that runs on your machine can run on a web page, with nothing to install for whoever opens it — one HTML file is the whole deliverable. It is the simplest way to share a demo, a tool, or a game that people can try with a single click.

## Example

```
$ loft --html game.loft            # write a self-contained game.html
$ # open game.html in a browser — no server or install needed

$ loft --native-wasm game.loft     # emit just game.wasm to embed yourself
```
