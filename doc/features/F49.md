# @F49 — REPL — interactive sessions

## What it is

An interactive session you start with `loft repl` (or just `loft` with no file). You type loft one line at a time and see each result straight away. It reopens your last session automatically; `loft repl --fresh` starts from a clean slate.

## How it aids you

You can try an expression, check what a function returns, or shape a struct without writing a whole program first. Whatever you define — variables, functions, types — stays available for the rest of the session, so you build an idea up step by step. It is the quickest way to answer "what does this do?".

## Example

```
$ loft repl
loft REPL — :help for commands, :quit to exit
loft> x = 40 + 2
loft> x
42
loft> fn dbl(n: integer) -> integer { n + n }
loft> dbl(x)
84
loft> :quit
```
