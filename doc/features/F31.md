# @F31 — `break` / `continue` + labelled forms

## What it is

`break` stops a loop early and `continue` skips straight to its next turn. To act on an outer loop from inside a nested one, name that loop's variable: `i#break` breaks the loop over `i`, and `i#continue` skips to its next turn.

## How it aids you

You leave a loop the moment you have what you need instead of running it to the end, and you can jump right out of several nested loops at once — no extra flags or bookkeeping.

## Example

```loft
fn main() {
    // continue: skip the value 3, add the rest
    sum = 0;
    for n in 1..=5 {
        if n == 3 { continue; }
        sum += n;
    }
    println("sum without 3: {sum}");                     // sum without 3: 12

    // break out of the OUTER loop from inside the inner one
    found = "";
    for i in 1..=3 {
        for j in 1..=3 {
            if i * j == 4 {
                found = "{i} and {j}";
                i#break;
            }
        }
    }
    println("first pair whose product is 4: {found}");   // first pair whose product is 4: 2 and 2
}
```
