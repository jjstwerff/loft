# @I72 — Parallel execution runtime

## What it does

Runs loft's parallel constructs (parallel loops and tasks) across multiple threads, coordinating the work and access to the shared store safely. It is the machinery behind the language's `par` features.

## Where it lives

`src/parallel.rs`
