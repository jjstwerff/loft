# @F51 — Debugger — breakpoints, frame capture, scripted RPC

## What it is

`loft debug prog.loft:12` runs your program and pauses it at line 12, dropping you into an interactive `(dbg)` prompt. From there you inspect variables (type a name to see its value), advance one line at a time with `:step` / `:next`, resume with `:continue`, and leave with `:quit`.

## How it aids you

Instead of scattering print statements through your code and re-running, you stop the program where it matters and look at the real values in the live frame. You can watch state change line by line, which makes it far easier to see where a result first goes wrong.

## Example

```
$ loft debug prog.loft:12
loft debugger — break at prog.loft:12.  :help for commands, :continue to run, :quit to exit
(dbg) total          # inspect a local by name
42
(dbg) :step          # run the next line
(dbg) :continue      # resume until the program ends
(dbg) :quit
```
