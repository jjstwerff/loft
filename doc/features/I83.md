# @I83 — Dev server (--serve / --rpc)

## What it does

Runs loft as a long-lived local server. `--serve` exposes an HTTP + WebSocket endpoint for browser-facing development; `--rpc` speaks a line-delimited JSON protocol so an editor or debugger can drive a session programmatically. Both keep one interpreter alive across many requests instead of starting fresh each time.

## Where it lives

`src/serve.rs` (HTTP / WebSocket), `src/rpc.rs` (NDJSON request/response)
