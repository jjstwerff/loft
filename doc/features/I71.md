# @I71 — DbRef pointers & collection keys

## What it does

Defines `DbRef`, loft's universal pointer — a triple of store number, record, and position that locates any value in the store — together with the key types used to index collections. Everything that refers to heap data does so through these.

## Where it lives

`src/keys.rs`
