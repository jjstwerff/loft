# @F7 — `hash<T[keys]>` keyed collection

## What it is

A collection of records that you look up by a key field. You give it a value for that field and it hands back the matching record straight away, with no searching through a list.

## How it aids you

When you need to find "the record with this name" over and over, a hash gives you the answer directly instead of scanning everything each time. You declare which field is the key, so every lookup reads naturally.

## Example

```loft
struct Person { name: text, age: integer }
struct Directory { people: hash<Person[name]> }
fn main() {
    dir = Directory { };
    dir.people = [ {name: "Ada", age: 36}, {name: "Bo", age: 20} ];
    dir.people += [ {name: "Cy", age: 51} ];
    println("Ada is {dir.people["Ada"].age}, Cy is {dir.people["Cy"].age}");
    // Ada is 36, Cy is 51
}
```
