# @F21 — References `&T` — parameters + write-back bindings

## What it is

Put `&` before a parameter's type to pass a variable by reference. The function then works on your actual variable, so any change it makes stays after the call returns. Without `&`, the function only sees a copy and your original is left alone.

## How it aids you

Let a function update your data in place — add to a running total, adjust a counter, fill in a field — without you having to catch a result and assign it back. It is the clear, visible way to say "this function will change what I hand it."

## Example

```loft
fn add_to(x: &integer, amount: integer) {
    x += amount;
}
fn main() {
    total = 10;
    add_to(total, 5);
    add_to(total, 100);
    println("total = {total}");    // total = 115
}
```
