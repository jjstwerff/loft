# @F11 — Tuples — anonymous fixed-arity `(T1, T2, …)`

## What it is

A fixed-size group of values that can each be a different type, written in parentheses like `(3, "three")`. You read the parts by position with `.0`, `.1`, and so on.

## How it aids you

When you want to pass or return a few related values together — a low and a high, or a code and a message — a tuple does it in one step, with no need to define a named type first.

## Example

```loft
fn min_max(a: integer, b: integer) -> (integer, integer) {
    if a <= b { (a, b) } else { (b, a) }
}
fn main() {
    pair: (integer, text) = (3, "three");
    println("{pair.0} = {pair.1}");
    (lo, hi) = min_max(9, 4);
    println("lo={lo} hi={hi}");
    // 3 = three
    // lo=4 hi=9
}
```
